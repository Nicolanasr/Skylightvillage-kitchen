# Skylight Kitchen Image Assets Directory

Place your image files in this directory:

### 1. Restaurant Thermal Receipt Logo
- **File Name**: `logo.png`
- **Path**: `public/logo.png`
- **Description**: This logo automatically prints centered at the top of 80mm POS thermal receipts and guest checks.

### 2. Menu Item Dish Images
- **Directory**: `public/images/menu/`
- **Example Files**: 
  - `public/images/menu/fattoush.jpg`
  - `public/images/menu/almaza.jpg`
  - `public/images/menu/grill.jpg`
- **Usage**: Reference these images in menu items using relative URLs (e.g., `/images/menu/fattoush.jpg`).
